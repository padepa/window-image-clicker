# Windows 图像识别自动点击工具

这是一个基于 Python 的简单桌面工具，支持多账号配置、每个账号最多 5 个图像识别点击点、全局热键启动/停止，以及中文界面。

## 功能

- 支持多个账号
- 每个账号最多 5 个识别点
- `F9` 启动任务
- `F8` 停止任务
- 使用模板图片做图像识别，不依赖固定坐标
- 配置保存到 `config.json`

## 安装

建议使用 Python 3.10 及以上版本。

```powershell
pip install -r requirements.txt
```

## 运行

```powershell
python app.py
```

## 使用方法

1. 新增账号。
2. 在账号下新增识别点。
3. 选中某个识别点后，设置：
   - 点位名称
   - 模板图片路径
   - 匹配阈值，默认 `0.85`
   - 点击次数
   - 点击间隔
4. 点击“应用识别点设置”。
5. 点击“保存配置”。
6. 按 `F9` 开始运行，按 `F8` 停止。

## 模板图片建议

- 尽量截取有明显特征的小区域，不要太大。
- 模板图片内容要稳定，避免动画或频繁变化的区域。
- 如果识别不到，可以把阈值从 `0.85` 降到 `0.75` 左右测试。
- 如果误识别较多，可以提高阈值，或者换更有特征的模板图。

## 说明

- 程序运行时会对当前屏幕截图做模板匹配，找到目标后点击模板中心位置。
- 当前版本按顺序轮询账号和识别点。
- 如果某些程序窗口启用了高权限，热键监听和点击可能需要以管理员身份运行本工具。

## 截图取模板

- 先在界面里选中一个识别点。
- 点击“截图取模板”按钮。
- 程序会进入全屏截图模式。
- 用鼠标拖出一个矩形区域，尽量只框住要识别的按钮或图标。
- 按回车保存模板图片，按 `Esc` 取消。
- 保存后的图片会自动写入 `templates` 目录，并自动回填到当前识别点。
