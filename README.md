# Windows 图像识别自动点击工具

这是一个基于 Python 的 Windows 桌面工具，适合用于你自己的窗口自动化测试、重复点击操作和图像匹配触发场景。它支持多账号、按窗口识别、截图生成模板、热键启动停止，以及中文界面。

## 直接下载

如果你只想直接运行，不想自己安装 Python，可以到 GitHub Release 下载最新 `exe`：

- Release 页面：<https://github.com/padepa/window-image-clicker/releases>
- 最新可执行文件：<https://github.com/padepa/window-image-clicker/releases/latest/download/auto_clicker_cn.exe>

## 功能

- 支持多个账号
- 每个账号最多 10 个识别点
- 支持为每个账号单独选择目标窗口
- 支持 `F9` 启动、`F8` 停止
- 使用模板图片做图像识别点击，不依赖固定坐标
- 支持截图生成模板
- 支持测试当前识别点
- 配置保存到本地 `config.json`

## 安装

建议使用 Python 3.10 及以上版本。

```powershell
pip install -r requirements.txt
```

## 运行

```powershell
python app.py
```

## 推荐使用顺序

第一次使用时，建议按下面顺序操作：

1. 新增一个账号。
2. 为该账号选择目标窗口。
3. 点击“保存账号设置”。
4. 在该账号下新增识别点。
5. 点击“截图生成模板”或“选择模板图”。
6. 设置匹配阈值、点击次数、点击间隔。
7. 点击“保存识别点设置”。
8. 先点“测试当前点”，确认识别和点击都正常。
9. 最后按 `F9` 开始运行，按 `F8` 停止。

## 目标窗口

- 如果为账号设置了目标窗口，截图、测试和自动运行都会只在这个窗口内识别。
- 如果目标程序没有出现在列表里，可以先点“刷新窗口列表”。
- 也可以先切到目标程序，再点“使用当前窗口”。

## 模板图片建议

- 尽量截取有明显特征的小区域，不要太大。
- 模板图片内容要稳定，避免动画或频繁变化的区域。
- 如果识别不到，可以把阈值从 `0.85` 降到 `0.75` 左右测试。
- 如果误识别较多，可以提高阈值，或者换更有特征的模板图。

## 截图生成模板

- 先在界面里选中一个识别点。
- 点击“截图生成模板”。
- 程序会打开一个截图预览窗口。
- 用鼠标拖出一个矩形区域，尽量只框住要识别的按钮或图标。
- 按回车保存模板图片，按 `Esc` 取消。
- 保存后的图片会自动写入 `templates` 目录，并自动回填到当前识别点。

## 说明

- 程序运行时会对当前屏幕或目标窗口截图做模板匹配，找到目标后点击模板中心位置。
- 当前版本按顺序轮询账号和识别点。
- 如果某些目标程序以管理员权限运行，热键监听和点击可能也需要以管理员身份运行本工具。
